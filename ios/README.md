# iOS app

The same Nuxt build, wrapped in [Capacitor 8](https://capacitorjs.com) exactly like Footballdle
(Swift Package Manager, no CocoaPods), and built in the cloud by [Codemagic](https://codemagic.io).
You don't need Xcode on your Mac.

| Piece                           | What it is                                                                                       |
| ------------------------------- | ------------------------------------------------------------------------------------------------ |
| `capacitor.config.ts`           | Bundle ID `uk.co.danhorne.dobiedash`, app name, web build folder                                 |
| `ios/`                          | The Xcode project. Committed. `ios/App/App/public` is generated and ignored                      |
| `codemagic.yaml`                | Cloud build: install → `npm run cap:sync` → sign → upload to TestFlight                          |
| `plugins/01.services.client.ts` | Swaps native services in when running inside the app                                             |
| `ios/App/App/*Plugin.swift`     | Game Center and iCloud save plugins (from Footballdle), registered in `MainViewController.swift` |
| `ios/App/App/App.entitlements`  | Game Center + iCloud key-value storage                                                           |
| `ios/App/DobieDash.storekit`    | Local StoreKit test file, generated by `npm run storekit` from `content/store.json`              |

npm plugins: RevenueCat (purchases), `@capacitor-community/admob` (ads + the tracking
prompt), local notifications, haptics, share. Info.plist carries Google's **test** AdMob app
id; Codemagic swaps in the real one.

```bash
npm run cap:sync   # nuxt generate + copy into the iOS project (Codemagic runs this)
```

## One-off Apple setup (reuses Footballdle's developer account)

1. **Bundle ID**: developer.apple.com → Identifiers → + → App ID → App →
   Explicit `uk.co.danhorne.dobiedash`, description `Dobie Dash`, with **Game Center** and
   **iCloud** ticked (both used from M4, ticked now so the profile never needs regenerating).
2. **App Store Connect**: Apps → + → New App → iOS, name `Dobie Dash`, English (UK),
   that bundle ID, SKU `dobiedash-ios`. Copy the numeric **Apple ID** from App Information into
   `codemagic.yaml` (`APP_STORE_APPLE_ID`).
3. **Provisioning profile**: Profiles → + → App Store Connect → this bundle ID → the existing
   Apple Distribution certificate → name `Dobie Dash App Store`.
4. **Codemagic**: add the `Dobie-Dash` repo as an app. The team's App Store Connect key
   (`Foodballdle ASC`) is shared. In Code signing identities → iOS provisioning profiles,
   fetch `Dobie Dash App Store`.
5. **Build**: Start new build → branch `main` → workflow **iOS → TestFlight**. About 15 minutes,
   then 5–30 minutes of processing in App Store Connect.
6. **TestFlight**: App Store Connect → Dobie Dash → TestFlight → Internal Testing → add yourself,
   then install from the TestFlight app.

## M4 setup (once)

Keys live in Codemagic, never in the repo: **Teams → Global variables and secrets**, group
`dobiedash` (the build expects the group to exist):

| Variable                | From                                                         |
| ----------------------- | ------------------------------------------------------------ |
| `REVENUECAT_APPLE_KEY`  | RevenueCat → Dobie Dash (App Store app) → API keys, `appl_…` |
| `ADMOB_APP_ID`          | AdMob → Apps → Dobie Dash → App settings, `ca-app-pub-…~…`   |
| `ADMOB_REWARDED_ID`     | AdMob → Ad units → Rewarded, `ca-app-pub-…/…`                |
| `ADMOB_INTERSTITIAL_ID` | AdMob → Ad units → Interstitial                              |

Leave the three AdMob ones out and the build uses Google's test ads.

1. **App Store Connect → Dobie Dash → Monetization → In-App Purchases**: create every product
   in `content/store.json` with id `uk.co.danhorne.dobiedash.<id>` (8 from the plan, plus
   `breeds.all` and the 11 `breed.<breed>` ones), type and price as listed, a display name and
   a review screenshot. `npm run storekit` lists them all in `ios/App/DobieDash.storekit`.
2. **Game Center** (Services tab): leaderboards `uk.co.danhorne.dobiedash.best` (all-time,
   high score) and `uk.co.danhorne.dobiedash.weekly` (recurring, resets Monday 00:00), and the
   30 achievements `uk.co.danhorne.dobiedash.trophy.<trophy>.<bronze|silver|gold>` (names from
   `content/trophies.json`).
3. **RevenueCat**: new App Store app with bundle id `uk.co.danhorne.dobiedash`, the same
   In-App Purchase key as Footballdle, import the products. Copy the `appl_` key to Codemagic.
4. **AdMob**: add the iOS app, then a Rewarded and an Interstitial ad unit. Copy the ids to
   Codemagic. Add `app-ads.txt` to danhorne.co.uk before launch.
5. **Sandbox tester**: App Store Connect → Users and Access → Sandbox → Testers. On the
   iPhone, Settings → Developer (or App Store) → Sandbox Account.
